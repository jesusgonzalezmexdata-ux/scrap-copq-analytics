# Scrap and cost of poor quality

Shift-level production records, cleaned and validated, turned into a cost Pareto, Laney p′ charts and a binomial model that values each improvement lever in pesos.

**Result:** MXN 1.23 M yearly saving from three levers, 14.5 % of COPQ (Synthetic plant data, median of 2,000 simulations).
